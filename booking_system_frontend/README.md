# Galaxium Travels Frontend

A modern, space-themed frontend for the Galaxium Travels interplanetary booking system. Built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Quick Start

```bash
npm install
npm run dev
```

App available at `http://localhost:5173`. Requires backend on `http://localhost:8080` (or set `VITE_API_URL`).

## Stack

- React 19 + TypeScript
- Vite + Tailwind CSS
- Framer Motion animations
- React Router v7
- Axios + React Hot Toast
- Lucide React icons
- date-fns

## Scripts

```bash
npm run dev      # dev server
npm run build    # production build
npm run lint     # eslint
npm run preview  # preview build
```
